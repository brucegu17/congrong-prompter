# 从容 · 离线提词录像

无需账号登录的 iPhone 竖屏提词工具，支持同机录像。纯静态网页，不收集或上传文稿、设置与录像。

## 安装
1. 用 Safari 普通模式打开网页，等待「离线已就绪」。
2. 分享 → 添加到主屏幕；如有「作为网页 App 打开」选项，保持开启。
3. 从桌面图标联网打开一次并再次确认离线就绪，随后可脱离电脑、断网使用。

## 使用
输入文稿 → 设置语速、字号与行距 → 进入提词 → 开启相机与麦克风 → 开始录像。
3 秒倒计时后提词与录像同步开始，全文结束后 2 秒自动停止。输出固定为 720×1280（9:16），提词文字不录入视频。连续拍摄复用相机；不用时点击关闭相机。保持页面前台，锁屏或切换 App 会中断录像。

文稿、语速、字号、行距、中英文节奏、发音校正、镜像及相机朝向自动保存在当前浏览器。支持 JSON 备份/恢复与 TXT 导入导出。浏览器私密模式结束、清除网站数据或系统清理存储可能导致数据丢失，请导出重要文稿与录像。

不同网址及浏览器容器的数据相互隔离，迁移时请复制文稿或使用备份导入；网页无法读取旧网站或其他用户的数据。不要把文件直接拷到 iPhone 文件 App 后期望获得完整录像功能，应通过 HTTPS 安装。

## 技术与许可
原生浏览器 MediaRecorder、Canvas、IndexedDB 和 Service Worker；无外部脚本依赖，无登录服务，无遥测。CMUdict 派生音节数据的版权许可保留在 index.html 内。

浏览器自动测试不能代替 iPhone 真机相机、麦克风、照片分享和长时间录像测试。首次请试录 10 秒确认。
